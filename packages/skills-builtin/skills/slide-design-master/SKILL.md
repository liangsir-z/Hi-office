# Edit for the audience

1. Read the slide and identify the question it answers. Keep its claims, units and source notes intact. If a metric is missing, do not invent it.
2. Choose a visual form from the material: a sequence for steps, a labeled chart for measurements, or a simple comparison for alternatives. For a single claim, let the headline carry it rather than adding decoration.
3. Lay out the most important item where the reader sees it first. Group related labels and values, keep text clear of other objects, and use consistent spacing. Use the presentation's existing theme if it serves the content.
4. Use live text and editable shapes when possible. Maintain contrast; if color encodes categories, label them directly too.
5. Read back the result. Check that nothing essential was cropped, the content still matches the source, and the labels make sense without speaker commentary.
